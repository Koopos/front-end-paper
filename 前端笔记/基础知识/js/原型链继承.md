简单来说，**原型链（Prototype Chain）** 是 JavaScript 实现继承的核心机制。你可以把它想象成一种“向上查找”的逻辑：当你试图访问一个对象的属性或方法时，如果该对象本身没有，JS 就会顺着一条“链条”去它的父级（原型）那里找，直到找到为止。

---

## 1. 核心概念：三个关键属性

理解原型链，首先要分清这三个经常让人头晕的概念：

- **`prototype`**：**显式原型**。只有**函数**（Function）才有的属性。它定义了由该构造函数创建的所有实例共享的属性和方法。
    
- **`__proto__`**：**隐式原型**。每个**对象**（包括函数）都有这个属性。它指向创建该对象的构造函数的 `prototype`。
    
- **`constructor`**：**构造函数**。原型对象上的一个属性，指向关联的构造函数。
    

---

## 2. 它是如何运作的？（查找机制）

当你访问 `obj.prop` 时，浏览器的引擎会执行以下步骤：

1. **检查自身**：属性是否直接存在于 `obj` 对象上？如果是，返回。
    
2. **向上寻找**：如果没有，则去 `obj.__proto__`（即构造函数的 `prototype`）中找。
    
3. **递归循环**：如果还没找到，就去原型对象的原型里找（`obj.__proto__.__proto__`）。
    
4. **终点**：如果一直找到 **`Object.prototype.__proto__`**（其值为 `null`）还没找到，则返回 `undefined`。
    

---

## 3. 代码示例

让我们用最经典的构造函数模式来看看：

JavaScript

```
function Animal(name) {
  this.name = name;
}

// 在原型上添加方法
Animal.prototype.eat = function() {
  console.log(this.name + " is eating.");
};

const dog = new Animal("Buddy");

dog.eat(); // "Buddy is eating."
```

**发生了什么？**

1. `dog` 实例本身并没有 `eat` 方法。
    
2. JS 引擎查看 `dog.__proto__`，它指向 `Animal.prototype`。
    
3. 在 `Animal.prototype` 中找到了 `eat`，执行成功！
    

---

## 4. 完整的原型链图谱

在 JS 中，几乎所有东西都是对象。如果你深入挖掘，会发现如下规律：

|**对象**|**__proto__ 指向**|
|---|---|
|**普通实例** (`dog`)|`Animal.prototype`|
|**构造函数原型** (`Animal.prototype`)|`Object.prototype`|
|**内置对象** (`Array`, `String`)|`Object.prototype`|
|**顶层原型** (`Object.prototype`)|**`null`** (链条终点)|

---

## 5. 为什么需要原型链？

- **节省内存**：不需要在每个实例上都重复创建相同的方法。所有实例共享同一个原型上的方法。
    
- **实现继承**：通过改变原型链的指向，可以让一个类继承另一个类的属性和方法。
    

> **小贴士**：在现代开发中，虽然我们更常用 `class` 语法糖，但其底层依然是基于原型链的。理解了原型链，你就理解了 JavaScript 的灵魂。
