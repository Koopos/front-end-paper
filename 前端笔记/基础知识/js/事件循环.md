
# 🧠 一、先一句话理解

👉 **事件循环 = JS 处理“同步 + 异步任务”的调度机制**

---

# ⚙️ 二、JS 为什么需要事件循环？

👉 因为 JavaScript 是：

👉 **单线程**

也就是说：

- 同一时间只能做一件事
- 不能阻塞（否则页面卡死）

所以需要：

👉 **事件循环来安排任务执行顺序**


# 📦 三、核心结构（非常重要🔥）

JS 运行时主要有 3 个东西：

### 1️⃣ 调用栈（Call Stack）

👉 执行同步代码

### 2️⃣ 任务队列（Task Queue）

分两种：

#### 🟡 宏任务（Macro Task）

- `setTimeout`
- `setInterval`
- DOM 事件
- `setImmediate`（Node）

#### 🔵 微任务（Micro Task）

- `Promise.then`
- `queueMicrotask`
- `MutationObserver`
### 3️⃣ 事件循环（Event Loop）

👉 负责不断检查：

- 栈空了吗？
- 有任务要执行吗？


# 🔄 四、执行流程（核心逻辑🔥）

👉 每一轮循环（tick）：

1. 执行同步代码（进入调用栈）
2. 清空所有 **微任务**
3. 执行一个 **宏任务**
4. 重复循环

```
console.log("1");

setTimeout(() => {
  console.log("2");
}, 0);

Promise.resolve().then(() => {
  console.log("3");
});

console.log("4");
```


## 👉 执行顺序分析

1️⃣ 同步代码：

1  
4

2️⃣ 微任务：

3

3️⃣ 宏任务：

2

---

## ✅ 最终输出：

1  
4  
3  
2
