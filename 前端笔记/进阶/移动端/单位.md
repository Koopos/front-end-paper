
## 绝对单位（固定大小）

| 单位   | 含义              |
| ---- | --------------- |
| `px` | 像素（最常用）         |
| `cm` | 厘米              |
| `mm` | 毫米              |
| `in` | 英寸（1in = 96px）  |
| `pt` | 点（1pt = 1/72in） |

**像素 = 屏幕上最小的显示点**

你看到的任何图像、文字，其实都是由无数个小点组成的，这些小点就是像素。

📺 举个例子：

- 一个屏幕分辨率是 **1920 × 1080**
- 意味着有：  
    👉 横向 1920 个像素  
    👉 纵向 1080 个像素

## 相对于视口（屏幕）

| 单位     | 含义       |
| ------ | -------- |
| `vw`   | 视口宽度的 1% |
| `vh`   | 视口高度的 1% |
| `vmin` | 较小的一边    |
| `vmax` | 较大的一边    |
