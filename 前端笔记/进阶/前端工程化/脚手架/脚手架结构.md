
前端“脚手架搭建过程”本质就是：  
👉 **用工具快速生成一个标准化项目结构 + 开发环境**

我给你讲一个**从 0 到能跑项目的完整流程（通用 + 实战）**👇

---

# 🧠 一、什么是前端脚手架？

👉 一句话理解：

> **帮你自动创建项目结构、配置工具链的工具**

比如：

- 自动配置：
    
    - 打包工具
        
    - 路由
        
    - 代码规范
        
    - 开发服务器
        

---

## 常见脚手架工具

- React：
    
    - Create React App（老牌）
        
    - Vite（主流推荐）
        
- Vue：
    
    - Vue CLI（逐渐被替代）
        
    - Vite（现在主流）
        

👉 现在基本统一趋势：**Vite 统治前端脚手架**

---

# 🚀 二、标准搭建流程（以 Vite 为例）

## ✅ 1. 初始化项目

```bash
npm create vite@latest
```

然后选择：

- 项目名
    
- 框架（React / Vue / Vanilla）
    
- 是否 TypeScript
    

---

## ✅ 2. 安装依赖

```bash
cd your-project
npm install
```

---

## ✅ 3. 启动项目

```bash
npm run dev
```

👉 浏览器访问：

```
http://localhost:5173
```

---

# 🧱 三、生成的项目结构（核心）

```id="y79k9s"
your-project/
├── public/
├── src/
│   ├── assets/
│   ├── components/
│   ├── App.jsx
│   └── main.jsx
├── index.html
├── package.json
└── vite.config.js
```

---

## 📌 关键文件说明

### `main.js / main.ts`

👉 入口文件（应用从这里启动）

---

### `App.vue / App.jsx`

👉 根组件

---

### `index.html`

👉 HTML 模板（Vite 特点：HTML 是入口）

---

### `vite.config.js`

👉 构建配置（代理、别名等）

---

# ⚙️ 四、脚手架到底帮你做了什么？

## 1️⃣ 构建工具（核心）

👉 现在基本是：

- Vite（底层用 esbuild + rollup）
    

---

## 2️⃣ 开发服务器

👉 支持：

- 热更新（HMR）
    
- 快速启动
    

---

## 3️⃣ 模块化支持

👉 支持：

- ES Module
    
- CSS/图片导入
    

---

## 4️⃣ 打包优化

👉 自动做：

- 压缩
    
- Tree Shaking
    
- 代码分割
    

---

# 🛠️ 五、实际项目必加配置（重点）

脚手架只是“起点”，你一般还要加👇

---

## ✅ 1. 路由

React：

```bash
npm install react-router-dom
```

Vue：

```bash
npm install vue-router
```

---

## ✅ 2. 状态管理

    - Redux / Zustand
        
- Vue：
    
    - Pinia（主流）
        

---

## ✅ 3. 网络请求

```bash
npm install axios
```

---

## ✅ 4. 代码规范

```bash
npm install eslint prettier -D
```

---

## ✅ 5. UI 组件库（可选）

- React：
    
    - Ant Design / MUI
        
- Vue：
    
    - Element Plus

# ⚡ 七、脚手架 vs 自己搭（理解很重要）

|方式|优点|缺点|
|---|---|---|
|脚手架|快速、标准化|灵活性低|
|自己搭（webpack）|完全可控|成本高|

👉 现在行业趋势：**90% 用脚手架（Vite）**

---

# 🎯 八、一句话总结

👉 **脚手架 = 帮你把“开发环境 + 项目结构 + 构建工具”一次性搭好**
