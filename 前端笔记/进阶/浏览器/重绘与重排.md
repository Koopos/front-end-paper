
# 🧠 一、什么是浏览器重排？

👉 **重排（Reflow）= 浏览器重新计算元素的“几何布局”**

也就是重新确定：

- 元素的位置（x / y）
- 元素的大小（width / height）
- 元素之间的关系（谁挤谁）

# 为什么重排很贵？

因为它是“连锁反应”：

👉 改一个元素 → 影响父元素 → 影响兄弟元素 → 整页重算

特别是在复杂页面中，性能会明显下降（卡顿）


# 如何减少重排（重点🔥）

## ✅ 1️⃣ 批量修改（避免反复操作）

❌ 错误：

div.style.width = "100px";  
div.style.height = "100px";  
div.style.margin = "10px";

✔ 正确：

div.style.cssText = "width:100px;height:100px;margin:10px;";

---

## ✅ 2️⃣ 使用 `class` 一次性改

div.classList.add("active");

👉 比多次 `style.xxx` 好

---

## ✅ 3️⃣ 避免频繁读写交替（经典坑）

❌：

div.style.width = "100px";  
console.log(div.offsetWidth); // 强制重排

✔：

div.style.width = "100px";  
// 不要立刻读布局

---

## ✅ 4️⃣ 使用 `display: none` 脱离文档流

div.style.display = "none";  
// 一顿操作  
div.style.display = "block";

👉 中间不会触发重排

---

## ✅ 5️⃣ 用 transform 替代位置变化（超级重要🔥）

❌：

left: 100px;

✔：

transform: translateX(100px);

👉 transform：

- 不触发重排
- 只触发合成（GPU）

# 什么是重绘（Repaint）？

👉 **重绘 = 浏览器重新“画”元素的外观，但不改变布局**

也就是说：

- 不改位置 ❌
- 不改大小 ❌
- 只改样式（颜色、阴影等） ✅
