

### 一、强制缓存（强缓存）

浏览器直接看本地缓存是否过期，**完全不发请求给服务器**。

#### 控制字段

1. **`Expires`**
    
    给一个具体过期时间，缺点：依赖客户端时间。
    
2. **`Cache-Control: max-age=xxx`**
    
    相对过期时间（秒），优先级更高，现在主流用法。
    
    常见值：
    
    - `max-age=3600` 缓存 1 小时
    - `no-cache` 不走强缓存，直接走协商缓存
    - `no-store` 完全不缓存
    

#### 表现

- 浏览器直接读缓存
- Network 面板显示：**200 OK (from disk cache)** 或 **(from memory cache)**

---

### 二、协商缓存（对比缓存）

浏览器**一定会发请求**给服务器，由服务器判断：

- 没变化 → 返回 **304 Not Modified**，用本地缓存
- 有变化 → 返回 **200 + 新内容**

#### 两组配对字段

1. **`Last-Modified` / `If-Modified-Since`**
    
    - 响应头：`Last-Modified: 上次修改时间`
    - 请求头：`If-Modified-Since: 上次时间`
    - 服务器对比时间，没变就 304
    
2. **`ETag` / `If-None-Match`**（优先级更高）
    
    - 响应头：`ETag: 文件指纹/版本号`
    - 请求头：`If-None-Match: 上次指纹`
    - 服务器对比指纹，更精准
    

#### 表现

- 一定会发请求
- 没变：**304 Not Modified**
- 变了：**200 OK + 新资源**

---

### 三、执行顺序

1. 先看**强制缓存**
    
    - 有效 → 直接用本地
    - 无效 → 走下一步
    
2. 再走**协商缓存**
    
    - 服务器说没变 → 304，用本地
    - 变了 → 200，用新内容
